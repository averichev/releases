## Состав каждого варианта

- `svg/mark-*.svg` — отдельный знак.
- `svg/horizontal-*.svg` — знак и название в строку.
- `svg/stacked-*.svg` — вертикальная компоновка.
- `svg/wordmark-*.svg` — только название.
- `svg/favicon.svg` — знак на скруглённой цветной подложке.
- `svg/app-icon.svg` — квадратная подложка без скругления для платформенной маски.
- `svg/maskable.svg` — квадратная подложка с дополнительным безопасным полем.
- `favicon.ico` — один ICO с изображениями 16, 24, 32, 48, 64, 128 и 256 px.

Четыре оформления: `color` для светлого фона, `dark` для тёмного, `black` и `white` для одноцветного применения. У знака и логотипов прозрачный фон; подложка есть только у иконок. В ICO фон за скруглением прозрачен.

SVG масштабируется до любого размера. Надпись переведена в контуры: установленный шрифт и сеть не нужны.

## Применение

Для favicon и размеров меньше 120 px используйте отдельный знак или иконку. Горизонтальный логотип с названием используйте от 120 px по ширине, вертикальный — от 160 px. Для экранов с высокой плотностью предпочтителен SVG или PNG с удвоенным размером.

Вокруг знака оставляйте свободное поле не меньше четверти его ширины. Если фон неоднородный, используйте иконку с подложкой. Белая версия предназначена для тёмного фона и выглядит пустой на белом фоне. Одноцветная версия сохраняет все части знака одним цветом.

В интерфейсе используется общий `frontend/src/components/Brand.tsx`: знак на лаймовой подложке и надпись в контурах. Выбранные SVG находятся в `frontend/src/assets/brand`, системные иконки — в `frontend/public`. Скрипт экспорта обновляет этот набор графики; копии для приложения обновляются отдельно, чтобы изменение альтернативных направлений не затрагивало UI.

## Исходники и повторный экспорт

Мастера находятся в `source/`: три знака и общая надпись в контурах. Палитры, компоновки и размеры задаются в `tools/export.py`; полная ведомость файлов — в `manifest.json`. Источники шрифта и промпты генеративного исследования описаны в [source/provenance.md](source/provenance.md).

Для повторного экспорта нужны Python 3 и `rsvg-convert` из librsvg. Это инструменты подготовки графики, приложение их не использует.

```sh
python3 assets/brand/tools/export.py
```

Галерея работает локально, без CDN и внешних шрифтов. Для просмотра через HTTP из корня проекта:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory assets/brand
```

Откройте http://127.0.0.1:8765/ .
