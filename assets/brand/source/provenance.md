# Происхождение графики

Три направления исследованы встроенным imagegen. Итоговые SVG нарисованы геометрическими контурами вручную: это векторная переработка идей, а не автоматическая трассировка растров. После уточнения пользователя палитры заменены на более яркие. Генеративные эскизы не являются мастер-файлами.

Промпты исследования находятся в `imagegen-prompts.json`. Режим генерации — встроенный инструмент, прозрачный фон.

Надпись «Релизы» набрана Manrope ExtraBold, вес 800, затем переведена в контуры с небольшим уплотнением межбуквенного интервала. Мастер `wordmark.svg` уже содержит все контуры и не требует установленного шрифта. Сам файл шрифта не включён в набор и не загружается приложением.

- Исходник шрифта: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/Manrope%5Bwght%5D.ttf
- Авторы: The Manrope Project Authors, https://github.com/googlefonts/manrope
- Лицензия: SIL Open Font License 1.1, копия в `Manrope-OFL.txt`.

Формы знаков находятся в трёх отдельных SVG. Атрибуты `data-color` задают роли цвета и используются только скриптом экспорта.
