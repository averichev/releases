## Первая команда и повтор

Команда из каталога `releases/0.3.0/` тестового стенда; `RELEASES_TOKEN` содержит созданный через панель секрет:

```sh
printf 'Authorization: Bearer %s\n' "$RELEASES_TOKEN" |
  curl --silent --show-error --fail-with-body --header @- \
    --write-out '\n%{http_code}\n' \
    -F 'release=@publish.json;type=application/json' \
    -F 'linux_binary=@acceptance-0.3.0-linux-x86_64' \
    -F 'mac_binary=@acceptance-0.3.0-darwin-aarch64' \
    'http://127.0.0.1:56872/api/v1/publish/cli-acceptance'
```

Первая команда: **HTTP 201**. Повтор той же команды: **HTTP 200**. Оба ответа содержат один и тот же JSON:

```json
{
  "published_at": 1795530860,
  "release_id": "0ef49d66-96fb-4cd2-ad86-7d5d6557876f",
  "status": "published",
  "version": "0.3.0"
}
```

В БД один релиз, два артефакта и одно событие публикации. В истории панели автор — **Токен CI Acceptance Rotation**, user_id — NULL. Повтор не добавил событие и не поменял дату. Проверка foreign_key_check ошибок не обнаружила.
